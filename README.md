## 🎯 **Sobre o Projeto**

Este portfólio é uma **demonstração prática** das minhas habilidades técnicas em desenvolvimento web, construído do zero com **tecnologias puras** (HTML5, CSS3, JavaScript ES6+) para mostrar domínio dos fundamentos. O projeto implementa padrões modernos de desenvolvimento e boas práticas da indústria.

**Objetivo:** Demonstrar competências técnicas para **oportunidades em empresas de desenvolvimento de software**, evidenciando capacidade de criar soluções web escaláveis e maintíveis.

## 🚀 **Como Executar**

### **Desenvolvimento Local**

```bash
# Clone o repositório
git clone https://github.com/MrHitalo/Projeto.git
cd Projeto

# Instale dependências de desenvolvimento
npm install

# Execute linting
npm run lint

# Formate código
npm run format

# Servidor local
python -m http.server 8080
# ou
npx serve .
```

### **Deploy**

- **GitHub Pages:** Deploy automático via Actions
- **Hospedagem:** Qualquer servidor estático (Netlify, Vercel)
