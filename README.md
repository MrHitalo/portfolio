[🔗 Demo (GitHub Pages)](https://SEU_USUARIO.github.io/Projeto) • [Repositório](https://github.com/SEU_USUARIO/Projeto)

Uma aplicação front-end criada para praticar e demonstrar habilidades em HTML, CSS e JavaScript, com foco em responsividade, acessibilidade e boas práticas.

## ✨ Destaques

- Layout responsivo (mobile-first) com atenção a tipografia e espaçamento
- Componentes interativos em JavaScript sem dependências pesadas
- Boas práticas de semântica e acessibilidade (atalhos de teclado, foco visível, ARIA quando necessário)
- Otimizações de performance (imagens otimizadas, lazy-load, minificação)
- SEO básico (metatags, Open Graph)
